원시 데이터 (Raw Data) 입력

[모드 1] 구글 시트 데이터 (권장): 헤더(text, host, domain_gt 등)를 포함하여 열 전체를 드래그 복사 후 붙여넣으세요.
[모드 2] 일반 텍스트 포맷: 대화 내용만 있을 경우 기존처럼 분할 감지합니다.

사용법 및 단축키 안내

🚀 [NEW] 구글 시트 데이터(다중 컬럼) 자동 감지 기능 지원!
구글 시트에서 domain_gt, text, host, interrupt 등의 헤더 행을 포함하여 엑셀 셀 전체를 복사해서 붙여넣으면, 방별로 자동 분할해주고 헤더 영역에 메타데이터를 표시해 줍니다. 보기 기준(디폴트) 역시 각 방에 매핑된 host로 자동 셋팅됩니다.

💡 텍스트 모드 사용법 (Legacy)

  1. 구글 시트의 단일 텍스트 셀 묶음이나 메모장 등에서 대화 기록 복사
  2. 우측 입력 창에 그대로 붙여넣기
    (※ 1. 화자:, 0 - 화자:, 번호 없는 포맷, 시트 묶음 "" 모두 자동 감지)
  3. 파싱하여 뷰어에 띄우기 버튼 클릭

⌨️ 단축키

  • Q : 이전 대화방으로 이동
  • E : 다음 대화방으로 이동
  • * 입력창에서 텍스트 작성 중일 때는 단축키가 작동하지 않습니다.
